# BBS Podcast Platform - Documentation Diagrams

This directory contains **industry-standard UML diagrams** for the BBS Podcast Platform documentation.

## Available Diagrams

1. **A1-usecase-diagram** - Use-Case-Diagramm showing all actors and their interactions
2. **A2-er-diagram** - ER-Diagramm with complete database schema
3. **A3-component-diagram** - Komponentendiagramm showing system architecture layers
4. **A4-sequence-authentication** - Sequenzdiagramm for JWT authentication flow
5. **A5-activity-episode-upload** - Aktivitätsdiagramm for episode upload and distribution
6. **A6-sequence-redcircle** - Sequenzdiagramm for RedCircle distribution workflow
7. **A7-deployment-diagram** - Deployment-Diagramm showing Docker infrastructure

## File Formats

Each diagram is available in three formats:

- **`.puml`** - PlantUML source file (editable, version-controlled)
- **`.png`** - PNG image (for Word, PowerPoint, print documentation)
- **`.svg`** - SVG vector graphic (for web, high-quality PDF)

## Regenerating Diagrams

### Automatic (Recommended)

Diagrams are automatically generated during setup:

```bash
npm run setup:dev
# or
npm run setup:prod
```

### Manual Generation

To regenerate all diagrams:

```bash
npm run docs:diagrams
```

This command will:
1. Check if Java is installed (required for PlantUML)
2. Install Java if missing (Windows: winget, macOS: brew, Linux: apt)
3. Check if PlantUML is installed
4. Install node-plantuml globally if needed
5. Generate PNG and SVG for all `.puml` files

### Requirements

- **Java** (JRE 11 or higher) - PlantUML requires Java
- **node-plantuml** (installed automatically)

## Editing Diagrams

1. Edit the `.puml` source files in a text editor or IDE
2. Use VS Code extension "PlantUML" by jebbs for live preview
3. Regenerate images with `npm run docs:diagrams`

## PlantUML Syntax

All diagrams use standard PlantUML syntax according to **ISO/IEC 19501** (UML standard).

### Quick Reference

- Use Case: `@startuml ... usecase ... @enduml`
- ER Diagram: `@startuml ... entity ... @enduml`
- Component: `@startuml ... component ... package ... @enduml`
- Sequence: `@startuml ... participant ... -> ... @enduml`
- Activity: `@startuml ... :action; ... if ... @enduml`
- Deployment: `@startuml ... node ... @enduml`

## Troubleshooting

### "Java not found"

**Windows:**
```bash
winget install EclipseAdoptium.Temurin.21.JDK
```

**macOS:**
```bash
brew install openjdk@21
```

**Linux:**
```bash
sudo apt update && sudo apt install default-jre
```

### "PlantUML not found"

```bash
npm install -g node-plantuml
```

### Diagrams not updating

1. Check if `.puml` files were modified
2. Run `npm run docs:diagrams` manually
3. Check console output for errors

## Contributing

When adding new diagrams:

1. Create a new `.puml` file in this directory
2. Follow naming convention: `A{number}-{name}.puml`
3. Run `npm run docs:diagrams` to generate images
4. Commit both `.puml` source and generated images
